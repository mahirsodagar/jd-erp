[Leads](02-leads.md). Your whole day is in the Leads menu.

**Admissions / front office** → [Getting Started](01-getting-started.md) →

## Words used throughout this guide

| Word | What it means here |
|---|---|
| **Lead** | A prospective student who has enquired but has not yet been admitted |
| **Counsellor** | The staff member responsible for following up a lead |
| **Follow-up** | A record of one interaction with a lead — a call, an email, a visit |
| **Outcome** | How that interaction went: Hot, Warm, Cold, Not Answering, Not Connected, or Enrolled |
| **Student** | A person who has submitted an application form and has a record in the system |
| **Enrolment** | A student joining a specific batch, in a specific program, semester, campus and academic year. A student can have several over time |
| **Batch** | A group of students who started together at one campus in one program and year |
| **Program** | A course of study (for example B.Des Fashion Design) |
| **Course** | A specific track inside a program |
| **Semester** | Semester 1, 2, 3 … |
| **Subject** | A taught module |
| **Slot** | One scheduled class: a batch + subject + instructor + classroom + date + time |
| **Time slot** | A reusable time block, such as "Slot 1, 9:30–11:00" |
| **Campus** | A physical location. Most lists only show data from *your* campus |
| **Institute** | The legal entity — JD Institute of Fashion Technology, or JD School of Design |
| **Academic year** | For example 2026-27. One year is marked as "current" |
| **Fee template** | The standard fee for a program in a given year and campus |
| **Installment** | One scheduled payment in a student's fee plan |
| **Receipt** | A record of money actually received |
| **Concession** | An approved discount on a student's fee |
| **Permission** | A switch that decides whether you can see or do something. Your administrator grants these through your role |
| **Role** | A named bundle of permissions, such as "HR Manager" or "Faculty" |
| **Portal** | The separate, simpler version of the system that students and parents log into |

## A few things that are true everywhere

1. **You only see your own campus.** Almost every list is filtered to the
   campus or campuses you are assigned to. If a colleague can see a record and
   you cannot, this is usually why.
2. **Menus you don't have access to are hidden, not greyed out.** A missing
   menu item means you have not been granted that permission — not that the
   feature is broken.
3. **Nothing important is ever really deleted.** Receipts get cancelled,
   employees get deactivated, master data gets switched off. This is deliberate
   so that history stays intact.
4. **The system logs who did what.** Every record keeps the name of the person
   who created it, edited it and approved it.
5. **When you change something, take a moment to check the effect.** Several
   actions ripple into other areas — each chapter has a short "What this
   affects" note at the end.
